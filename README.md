# XXIX Новосибирский полумарафон Раевича — анализ результатов

Анализ результатов [Сибирского фестиваля бега / полумарафона Раевича](https://startimer.online/timing-lite/20260912-novosibirsk) (12 сентября 2026).

**Гипотеза:** на полумарафоне поле «спортивнее» (распределение ближе к быстрым временам), на 10/5 км — массовее (масса ближе к медленному краю).

## Быстрый старт

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

# 1) скачать протокол с startimer.online (WebSocket)
python src/fetch_results.py --out data

# 2) tidy-таблица + нормировки
python src/prepare_data.py

# 3) графики → figures/*.png
MPLCONFIGDIR=.mplconfig python src/plot_analysis.py
```

## Нормировки

- **min–max:** `(t − t_min) / (t_max − t_min)` — прямо под гипотезу о форме
- **p01–p99:** робастный вариант без ультра-аутлайеров
- **t / t_победителя**, **t / median**
- **перцентиль** внутри дистанции
- **Riegel → эквивалент 10 км:** `T₂ = T₁ · (10/D)^1.06`

## Замечания

- При пагинации Startimer иногда отдаёт пересекающиеся страницы — в `prepare_data.py` дубликаты `race+bib` удаляются.
- Min–max нормировка ломается одной «черепахой»; для сравнений смотрите `00` / `00b` / `02`.
- Эстафета в сравнительные графики гипотезы не входит (другая природа результата).
